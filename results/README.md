scripts in `experiments/`. The full results (including trained model
checkpoints and intermediate analysis files) are archived on Google Drive
due to their size (~8 GB).

## What is Included vs. Regeneratable

| Content | In results/ | Regeneratable |
|---|---|---|
| Trained model checkpoints (.zip) | Yes | Yes (`python experiments/...`) |
| Figure source data (CSVs) | Yes | Yes |
| Intermediate plots (PNGs/PDFs) | Yes | Yes |
| Statistical summaries | See `repro/statistics/` | Yes |

All results can be regenerated by running the experiment scripts:

```bash
python main.py run-all
```
