# Historical Container Recipes

These Docker and Apptainer files record the attempt to capture the
`smn` environment used for the original analysis. The recorded lock files
include Windows-specific binaries and a local editable installation path.
A fresh Linux build requires a platform-specific dependency lock.

For a clean install and a working tutorial or table replay, use the
[source installation](../../README.md#install-cytoneighbor) and
[reproduction guide](../). The historical recipe and lock hashes are
recorded in [repro_manifest.csv](../repro_manifest.csv).
